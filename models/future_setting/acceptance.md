# TCCO2-008 acceptance protocol

Freeze this protocol and the following inputs before sampling. Fit one synthetic cohort of 160 independent setting summaries with fixed generator seed 88031, true parameters (1, log(9), 2, 0.50, −0.4), and known positive sampling covariances. Simulate each latent setting and its sampling noise separately. Use an independently integrated normal mixture at the generating parameters for truth. Allow 1.5 mmHg in each predictive endpoint, 0.10 in threshold probability and one support step for inverse quantiles, accounting for finite synthetic-study sampling. Report the observed errors. This is one recovery case, not a coverage study.

Use four chains with seed 88032, at least 1,000 warmup iterations, target acceptance 0.95, and initially 4,000 retained draws per chain. If only precision is inadequate, double retained draws with the same seeds until the target is reached (retain evidence at each doubling) and retain each attempt. Stop on a sampler diagnostic failure. Require rank-normalized R-hat <1.01, bulk/tail ESS ≥400 and zero post-warmup divergences. Estimate Monte Carlo error from contiguous within-chain batches and require ≤0.025 mmHg per predictive endpoint and ≤0.00025 per threshold probability. For discrete quantiles require the two-MCSE bounds on the left and right cumulative masses to identify the same support point. Compare quadrature orders 32 and 64 separately (≤0.01 mmHg and ≤0.0001 probability, identical discrete quantiles). If integration is insufficient, refine both orders without changing the posterior.

Additional checks cover the analytic bivariate normal convolution against independent latent integration, correlated and degenerate heterogeneity, density normalization, inverse order and sign, unit conversion of the observations and priors, actual Stan diagnostics, and posterior replication of the location, spread and correlation of the two observed summaries. Block a stratum when any included source unit has an unresolved material conflict. Preserve the row and its reason in the run manifest.

The initial engineering run stopped at 64,000 draws per chain for LFT with probability MCSE 0.000443. The numerical resource limit was extended for the same model, seed, and precision criteria.
